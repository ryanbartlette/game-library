DIRT RALLY — WEBSITE FILES

Upload the entire dirt-rally folder to your web server, preserving the assets/ subfolders.
Open dirt_rally.html through your website.

Image files are in assets/images/. Audio files are in assets/audio/.
Paths are relative to dirt_rally.html.

Note: The game uses Three.js from a public CDN and therefore needs an internet connection.
The original combined engine includes some unused canyon-racing assets; these are retained to avoid breaking existing code.
